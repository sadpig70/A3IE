# STEP 4 — System Idea Generation Prompt

Using the 10 insights from STEP 3, generate 3 new system ideas.

Each system idea must follow the A3IE structure:

## [Insight Layer I]
- List all relevant insights

## [Hypothesis Layer H]
- Logical interpretation linking insights

## [Creation Layer C]
- Full system concept
- Core architecture or mechanism
- Operating principles

## [Scenario Layer S] (optional)
- Future assumptions (market/policy shifts, industry behavior, etc.)
